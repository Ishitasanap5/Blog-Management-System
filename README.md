Full Stack MERN Blog Application

a full-stack MERN blog management system that allows users to register, log in, and create, edit, and manage blog posts with secure authentication and image uploads.



## 🚀 Features

- User Registration & Login (JWT Authentication)
- Create, Read, Update, Delete (CRUD) Blog Posts
- Protected Routes
- Image Upload Support (Cloudinary)
- Rate Limiting for API security
- RESTful API architecture
- Responsive frontend UI

---

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Axios
- Tailwind CSS (if used)

### Backend
- Node.js
- Express.js
- MongoDB & Mongoose
- JWT Authentication
- Cloudinary
